a simple vegetable growing cost calculator

# 蔬菜种植成本计算器

一个面向园艺学习者的简单练习项目，
用于记录蔬菜种植相关成本，并计算每亩成本。

## 为什么做这个项目？

我是一名园艺专业本科生，希望通过这个项目
练习数据整理、基础计算和 AI 辅助开发。

## 计划实现的功能

- 记录种植面积
- 记录种子、人工、肥料等成本
- 计算总成本
- 计算每亩成本

## 技术路线

- 第一阶段：整理需求和计算公式
- 第二阶段：制作简单的网页界面
- 第三阶段：测试计算结果
- 第四阶段：根据反馈继续改进

## 当前状态

目前处于学习和开发阶段，尚未完成全部功能。

## 使用说明

当前版本是项目介绍和开发计划，
暂时还不能用于实际生产经营决策。
